## Coverage and provenance

All **39** guide pages discovered through the entry page, linked guide pages, advertised sitemap and LLM index were retrieved on **18 October 2026**. The requested guide entry now redirects to Deepline’s workflow catalogue. Coverage includes all publicly discoverable linked guide pages on that date; it does not assert coverage of private or unlinked material.

The machine-readable coverage register is stored at `apps/pipedrive/data/deepline-guides.json`. It preserves the original source title, URL, read date and source hash; a source title or URL can legitimately name HubSpot even when the destination guide now targets Pipedrive. Deepline Plays, Monitors and provider-specific features are distinct from the proposed CRM design. The content is newly authored; no broad redistribution licence for source material is assumed. Keep private customer information, credentials and restricted provider payloads out of public examples.

## Before using a recipe

Inspect Pipedrive permissions, [endpoint scopes](https://pipedrive.readme.io/docs/marketplace-scopes-and-permissions-explanations), account-specific [custom-field keys](https://pipedrive.readme.io/docs/core-api-concepts-custom-fields) and the chosen API version before implementation. Persons and organizations are distinct from users; deals use stage and pipeline IDs, and follow-up work uses activities. Check the [Pipedrive API reference](/docs/reference/pipedrive-api), validate a small cohort and approve each proposed change before publishing it. Native automation availability and provider rights require their own checks; this site installs no integration, purchases no data and never writes to a CRM.
