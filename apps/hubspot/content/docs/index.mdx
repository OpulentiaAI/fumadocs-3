## Built from practice, not promises

This handbook combines the sponsor-context showcase, the agent operating patterns in **icantbelieveitsnotagi**, the **HubSpot agent CLI skills**, and original HubSpot adaptations of the **Deepline guide library**. Every adaptation links to its source and separates upstream behaviour from implementation advice.

Browse the [source register](/docs/reference/sources) for provenance and the [best-practice library](/docs/best-practices) for guide coverage. These are implementation guides, not a claim that the workflows have been executed in your HubSpot portal.
