## Coverage and provenance

All **39** guide pages discovered through the entry page, linked guide pages, advertised sitemap and LLM index were retrieved on **18 October 2026**. The requested guide entry now redirects to Deepline’s workflow catalogue. Coverage includes all publicly discoverable linked guide pages on that date; it does not assert coverage of private or unlinked material.

The machine-readable coverage register is stored at `apps/hubspot/data/deepline-guides.json`. Each page retains its original source URL. Deepline Plays, Monitors and provider-specific features are described separately from proposed HubSpot equivalents. The content is newly authored; no broad redistribution licence for Deepline source material is assumed.

## Before using a recipe

Inspect your HubSpot subscription, scopes and live schema. Validate the smallest useful test cohort, obtain approval for the exact proposed writes and verify the resulting record state. The site itself never writes to a CRM.
