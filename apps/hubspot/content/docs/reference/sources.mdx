## What the research establishes

The sponsor source has substantive implementation behind its README: a six-key evidence envelope, compliance and client-decision gates, a draft renderer that refuses blocked targets, a validator and a dashboard that reads a run packet on each request. Its client materials are supplied claims, not independent verification. The included PDF and PPTX were not independently re-extracted for this starter; campaign details are attributed to the repository's text extracts and structured packet.

The HubSpot source is a collection of 18 skills and supporting examples, not the CLI implementation. Command syntax was checked against those files. No HubSpot login, query or mutation was executed. Live command help, schema, permissions and portal-specific IDs still need checking before use.

The installation repository is a distribution wrapper, not a tracked orchestration engine. Its shell source checks platform and signatures, stages a copy and refuses an existing destination. Provider consent, knowledge-store ownership and recurring-runner scope are operator instructions. Neither the release archive nor the packaged runtime was inspected or launched.

## Installation repository: no explicit reuse grant found

The complete tracked inventory at the inspected commit contains only the README, setup guide and installer. No licence file or explicit general licence grant was found in them. Treat its code and prose as reference-only unless the rights holder grants permission; do not copy the installer or setup guide into a product on the assumption that a public repository is open-source licensed.

The orchestration guide here describes observed boundaries in original language. It does not reproduce the unlicensed setup prose or claim that the packaged runtime enforces a task policy.

## Fixture provenance

The offline `fixtures/sponsor-crm.json` contains invented companies, contacts, domains, deals and local associations. Category archetypes and package labels map to cited showcase files, while identities and amounts are synthetic. It is neither a portal export nor a ready-to-run import payload. See [seed-data mapping](/docs/guides/seed-data) for the promotion boundary and [safe writes](/docs/guides/safe-writes) before any separately authorised sandbox import.

These summaries are practical reuse guidance, not legal advice. Resolve uncertain rights with the relevant rights holder before redistributing substantial source material.
